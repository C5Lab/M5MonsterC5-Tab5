Choose **Start Bluetooth story** in the browser sidebar. On Grove, open Bluetooth
then BT Scan & Locate, choose NEURODECK-07, watch the signal and return using the
locator's Back button. The four-step definition lives in
`tools/ui_emulator/web/stories.mjs`, including instructions and native flow references.

Progress uses native discovery, locator, RSSI and Back events. The signal step
requires three different valid readings over at least two seconds of a viewing
window; a long gap in samples resets the window. A disconnected signal, wrong
device, another module or a hidden locator cannot supply completion evidence.

Restart story clears guide progress only and requires a fresh scan/Rescan.
Free exploration hides the guide without stopping the device. There is no manual
Next button, story storage or generated durable SD state. Reload/reset clears
progress. Fullscreen includes both guide and device while guidance is active.

Native browser acceptance covers four rotations, ordinary wall-clock progress,
wrong target/module, background locator, restart, reload, no signal and fullscreen.
Screenshots are generated by those tests: [portrait](bluetooth-story-0.png) and
[landscape](bluetooth-story-1.png). Built Wasm is routed through Playwright in
these tests to isolate native behavior from intermittent localhost HTTP resets.
